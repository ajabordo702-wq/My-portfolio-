PERSONAL PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser (or use the VS Code Live Server extension).
4. Use the navigation menu to visit Home, About Me, Portfolio, Skills, and Contact.

IMPORTANT: PERSONALIZE BEFORE SUBMISSION
- Replace "Your Name" and "YN" with your own name/initials.
- Update the About Me details, school, course, location, email, and social media.
- Replace the sample project titles and descriptions with your real projects.
- Replace the sample skill names and progress bars with your actual skills.
- The project artwork blocks are placeholders. You can replace them with your own screenshots/images.
- The contact form is a front-end demo only. It does not send emails until connected to a backend or form service.
